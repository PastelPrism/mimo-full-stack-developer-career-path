## 🎓 Curriculum Overview

**Mimo Full-Stack Developer Career Path** consists of 20 sections. Each section contains 1 big project and multiple extra projects.   
The total of projects for this curriculum is 61. The lessons consists of small pieces of information followed by multiple choice questions.    
Below you'll find the platform projects and challenge projects I’ve completed so far or am (currently) working on.
